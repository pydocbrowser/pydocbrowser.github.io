class documentation

class TypedDict(abstract.Dict): (source)

View In Hierarchy

Representation of TypedDict instances. Internally, a TypedDict is a dict with a restricted set of string keys allowed, each with a fixed type. We implement it as a subclass of Dict, with some type checks wrapped around key accesses. If a check fails, we simply add an error to the logs and then continue processing the method as though it were a regular dict.

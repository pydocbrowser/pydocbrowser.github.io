pylint.extensions.emptystring.CompareToEmptyStringChecker

class documentation

class CompareToEmptyStringChecker(checkers.BaseChecker): (source)

View In Hierarchy

Checks for comparisons to empty string. Most of the time you should use the fact that empty strings are false. An exception to this rule is when an empty string value is allowed in the program and has a different meaning than None!
